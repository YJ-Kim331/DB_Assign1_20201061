# DB_Assign1_20201061

# Overview
This repository contains Python implementations of a B-Tree and a B+-Tree. The code evaluates and compares their performance across various operations: insertion, point search, range query, and deletion.

# File Structure
* `main.py`: Main execution script for performance testing.
* `b_tree.py`: B-Tree implementation.
* `bplus_tree.py`: B+-Tree implementation.
* `student.csv`: Dataset used for testing.

# How to Run
1. Place `student.csv` in the same directory as the Python scripts.
2. Execute the main script via command line:
   ```bash
   python main.py
